# Melvor Idle 2 中文 Wiki

非官方中文玩家资料站，内容根据 Melvor Idle 2 游戏数据文件整理。

- **在线访问**：<https://leager-zju.github.io/MelvorIdle2-WIKI/>
- **离线使用**：下载并解压成品 ZIP，双击其中的 `index.html` 即可在浏览器里离线使用。 [下载离线版](https://leager-zju.github.io/MelvorIdle2-WIKI/melvor-idle-2-wiki.zip)

站点地图 [sitemap.xml](https://leager-zju.github.io/MelvorIdle2-WIKI/sitemap.xml) 提供首页的规范网址，供 Google Search Console、Bing Webmaster Tools 和百度搜索资源平台提交。

游戏内容与图像版权归 Games by Malcs 所有。本站与官方无关，数值为游戏基础配置，实际效果以游戏内为准。

## 页面结构（参照 [Melvor Idle Wiki](https://wiki.melvoridle.com/w/Main_Page)）

- 顶栏：游戏 Logo、全站搜索（输入时下拉建议，回车进入搜索结果页，按 `/` 快速聚焦）、随机条目、收藏。
- 左侧站点导航：首页、新手指南、按战斗 / 非战斗 / 被动分组的全部技能、参考表和工具；窄屏折叠为 ☰ 菜单。
- 首页：欢迎说明与游戏版本（从安装包读取）、统计、主导航框（Navbox）、新手入门、各阶段金币获取指南（按等级段列出每小时金币最高的采集动作，导入存档后按存档加成计算）、最近浏览。
- 条目页：右浮信息框（Infobox：图标、英文名、种类、来源 / 用途摘要、属性、出售价格）、一句导语、来源与用途表、装备属性、相关条目导航框和底部主导航框；可查看“链入页面”。
- 鼠标悬停或用键盘聚焦条目和技能链接，可查看概览。物品概览还会列出部分来源、消耗用途和使用效果。
- 搜索结果页可按类别筛选；“全部条目”索引列出所有类别。页脚显示数据版本。
- 当前版本尚未开放的生火篝火及其商店解锁项目已从 Wiki 排除。
- 数据中概率为 0 或数量为 0 的未完成占位产出（例如花卉“产出”普通原木）不再显示为物品来源。
- 跨多个技能的表格按技能拆分，以技能名为小标题（物品表、工匠配方、宠物、精通任务、物品来源 / 用途等）；只属于一个技能的表保持单表。
- 超过 15 行的表格显示为固定高度的滚动框，表头固定；打印时完整展开。
- 页面与表格 CSV 的数值四舍五入至最多两位小数，计算和排序使用原始精度。
- 精通公会阶级表显示晋升所需的累计精通点数、进度比例及奖励，技能页与参考表一致。
- 精通公会任务表列出任务类别和完成奖励点数。「要求 / 目标」显示进度、达成条件或触发动作，并链接到有关联的任务。
- “或”条件与前一条合并为一行，如“伐木 等级 8 或 农务 等级 6”。

## 技能 Boosts：主要入口

首页 → 技能 → 具体技能页面 → **Boosts**。25 个技能都有专页；Boosts 入口只保留在具体技能页面，导航、首页、技能列表、物品、装备、战斗和攻略页均不提供独立入口。

- 递归索引已收录对象：2,566 条数值修饰 + 199 条战斗效果触发，来自 1,823 个对象来源。
- 按经验、间隔、翻倍、保留、产出、潜行、战斗与其他效果分类，可按来源类型、名称、效果筛选；全局修饰默认包含。
- 来源包含物品、工具腰带、战斗装备、药水、食物、商店、精通、宠物、星座节点、套装、事件、动物变种、干扰、效果和操作模板。
- 展开每条的“生效条件与获取途径”，查看范围、配方或目标限制、动态缩放、消耗触发、等级条件、套装件数和获取来源。占星节点会展示所属星座和额外解锁条件。
- 星座条目直接列出主要与次要节点的效果、说明和额外解锁条件。次要节点的知识门槛按解锁次数列出。
- 副作用和测试内容保留；不会把所有行简单求和为“最终加成”。战斗通用效果列入各战斗技能，并保留具体适用条件。
- 银行等非技能系统加成有独立入口；覆盖索引不静默丢弃作用域未确定的记录。当前所有记录已找到技能或通用系统归属，归属推断不能替代实际运行时适用性验证。
- 装备基础攻击 / 防御属性在装备表与对比页；来源条目也保留玩家说明，可查具体使用效果。

## 其他玩家查询功能

- 10,929 个数据对象，覆盖物品、敌人、配方、商店、任务、区域、精通、占星等。
- 2,433 个可直接显示的游戏图像资源。安装包未提供图片的条目保留文字，不生成替代游戏美术。
- 技能页：配方、等级、材料、基础经验与周期、产物期望价值、精通、宠物和 Boosts。
- 所有配方表都有“产物期望价值”列：按基础概率与出售价格估算每次动作的产物售价（扒窃按每次成功计），并按基础周期折算每小时金币；未计翻倍、保留、加成和材料成本。
- **导入存档**：点顶栏“导入存档”，选择游戏存档文件（Steam 版在 `%APPDATA%\Games By Malcs\Melvor Idle 2\steam\<Steam ID>\saves\` 下的 `.sav` 文件，也可选 `.bak` 备份；点“选择存档文件…”会先复制该目录路径，在弹出窗口地址栏粘贴即可跳转），或粘贴游戏导出的存档字符串。存档只在浏览器里解析和保存，不会上传。导入后，技能页“配方与等级解锁”表的 XP、周期、XP/h 与产物期望价值按你的加成计算（表头标“（存档）”），表上方列出用到的每一项加成；“清除存档”恢复基础值。计入工具腰带、商店升级、占星节点、宠物和精通公会阶级奖励中无附加条件的经验、间隔、翻倍与产物数量加成；药水、装备套装、事件、战斗效果、保留和材料成本不计。存档用 Brotli 压缩，解码使用随站点发布的 Google Brotli 解码器（MIT，见 `vendor/brotli/`）。
- **按存档筛选**：各技能页和精通任务参考表可勾选“隐藏已完成的任务”，商店可勾选“隐藏已购买的一次性条目”。完成状态无法从存档确认的条件任务、可重复购买的商品仍会显示。此前已导入存档的玩家可重新导入，以识别靠触发标记完成的任务。
- 物品页：直接获取与消耗用途分表，显示对应的产物、用途与条件；掉落表按入口概率与权重展示基础概率。
- 物品、敌人、区域、地下城、商店等参考表支持筛选、排序和 CSV 导出。
- **敌人**按战斗区域、屠杀者区域、黑暗区域和地下城分表。每个子区域列出掉落物、基础数量范围和掉落概率，可从本页目录直接跳转。单次击杀价值包含直接金币与物品出售价格。地下城的通关奖励单独结算。导入存档后，已装备和长期生效的物品、可埋葬物与金币翻倍计入价值期望。临时和有条件的加成未计入。此前导入的存档可重新导入以读取当前战斗装备。
- 商店购买页按游戏的商店类别分区，区内按子类别列出购买项目。例如「采矿」下有「采矿工具」和「采矿常规升级」。
- 装备基础属性对比；标准技能经验表、升级时间、独立掉落概率与生产材料计算。
- 「工具 → 战斗模拟器」将进攻、躲避、战力与防护、生命与护甲集中在同一「战斗属性」区，宽屏以三列呈现。可选怪并按设定时长估算累计承伤、击杀数、死亡比例和基础掉落期望。已知未计入的特殊机制会随结果列出。
- 二代新手解锁路线、训练 / 加成查询流程、赚钱与战斗分析入口、机制 FAQ 和术语。
- 页面深链接、浏览器前进后退、收藏和最近浏览。
- 节标题统一样式。右侧常驻目录随阅读位置展开当前分组的次级标题，点击任意可见标题可直接跳转。
- 所有页面展示面向玩家的结果、效果、生效条件和获取途径，不提供 JSON、内部标识、字段路径或组件配置查看器。随等级变化的效果按每级收益说明；内部提取数据仅保留在文件中用于重建。

## 数据与边界

快照：2026-11-18 的游戏安装文件（v0.11.6）。核心来源为 `unpacked/Data/Packages/MelvorBase.json` 与 `unpacked/Locale/zh_CN.po`。提取出的 14,741 个文件合计 518,989,527 字节，全部通过 PCK 目录 MD5 校验；源 EXE 哈希见 `extraction-report.json`。

参考初代 Wiki 的玩家查询功能，不复制初代的攻略正文、DLC 数据或平衡数值。账户、多人编辑、修订历史与讨论后台按用户确认排除。功能对应见 `FEATURES.md`。

数值是基础配置，含可能未开放、占位或敌方内容。直接获取表不代表当前角色可获得。条件组合、互斥、动态缩放与真实叠加仍以游戏运行时为准；阶段条件概率不等于每次动作的最终概率。

游戏 DLL 已通过 .NET 元数据 / IL 只读检查，未加载执行游戏代码。经验曲线、伐木、工匠步骤与掉落入口的 IL 证据保存在本地 `mechanics-il.txt`（反汇编内容，不随仓库发布）。标准技能按 DLL 的乘方基数方式计算：99 级为 **13,034,427 XP**，与初代常见数值不同；此值也已用 .NET Math 核对。特殊技巧与动物日志不套用此经验表。生产周期的推算有明确假设，不能替代实际动作成功率、额外等待和加成计算。

原游戏、安装 DLL 与存档未修改。Godot 导入资源保留导出格式，未还原成可编辑工程；空壳 C# 文件不是源代码。

## 更新与验证

Steam 更新游戏后，在 `wiki/` 目录运行一条命令。需要 Python 3.10+ 和 Node.js：

```powershell
python update.py
```

默认读取上一级目录的 `Melvor2.exe`。Wiki 放在其他目录时，可以运行 `python update.py "D:\SteamLibrary\steamapps\common\Melvor Idle 2\Melvor2.exe"`。

脚本从游戏安装包重新解包数据、中文翻译和图标，生成整站并运行验证。通过后更新本地的 `index.html`、`assets/` 和两份报告。双击生成的 `index.html` 即可浏览。验证失败时保留本地上一次构建结果。精确数值回归适用于 v0.11.6 游戏快照。

更新使用 `.wiki-update/` 临时目录，完成后自动清理。若进程被强制结束，确认没有更新在运行后，可移走残留的 `.wiki-update/` 再重试。原有的 `python extract.py`、`python build.py`、`node verify.cjs` 仍可用于分步维护，解包目录 `unpacked/` 由分步解包维护。提取器支持未加密的 PCK v3/v4。游戏如更改资源格式、字段结构或游戏机制，可能需要先调整脚本或 Wiki 逻辑。

### 发布 Wiki

推送源码到 `main` 后，Windows 更新端检测最新提交并核对 Steam 公开分支的 Build ID。游戏有更新时由已登录的 Steam 客户端处理，安装完成后才重新提取数据。游戏与提取逻辑没有变化时，使用本地缓存的数据和图标重新构建页面。成品通过本地验证后，GitHub Actions 再验证并部署 Pages，同时更新离线 ZIP。更新、构建或验证失败时，原发布继续服务。 [构建与部署记录](https://github.com/Leager-zju/MelvorIdle2-WIKI/actions/workflows/pages.yml)

更新端使用 Windows 计划任务 `Melvor Idle 2 Wiki Publisher`，每分钟检查一次。Windows 用户需要登录，Steam 需要保持登录以处理游戏更新。游戏运行时，任务会等它退出再请求更新。可用 `python steam-publish.py --steam "D:\steam\steam.exe" --check` 检查版本和 GitHub 连通性，日志在 `.wiki-steam/updater.log`。公开 Build ID 通过 SteamCMD 元数据镜像查询，镜像不可用时保留线上版本。 [元数据来源](https://api.steamcmd.net/v1/info/3218350)

自动验证覆盖玩家展示无内部字段、Boosts 仅在技能详情页有入口、全部对象渲染、全部技能 / Boosts 页面、修饰与触发数量、来源链、中英文搜索、掉落权重、经验曲线、生产、对比、CSV 转义和输入边界，统计见 `verification-report.json`。浏览器已验收 Boosts 来源筛选、占星来源链、数值排序、经验与掉率计算及技能导航；未逐个在游戏中实测所有加成。

可选的只读 IL 工具源码位于 `tools/Inspect/`，需要 .NET 9 SDK。查看某类型或方法：

```powershell
dotnet run --project wiki/tools/Inspect -- data_GamesByMalcs.Melvor2_windows_x86_64/GamesByMalcs.Melvor2.dll StandardExperienceTable
dotnet run --project wiki/tools/Inspect -- data_GamesByMalcs.Melvor2_windows_x86_64/GamesByMalcs.Melvor2.dll ArtisanActionStats:GetSteps
```

格式依据：[Godot PCK 读取实现](https://github.com/godotengine/godot/blob/master/core/io/file_access_pack.cpp)、[Godot 纹理读取实现](https://github.com/godotengine/godot/blob/master/scene/resources/compressed_texture.cpp)。
